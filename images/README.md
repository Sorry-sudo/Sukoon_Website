# Sukoon Resorts - Image Upload Guide

Please upload your resort images to the `images/` folder with the following names:

## Required Images

### 1. `images/hero-resort.jpg`
- **Purpose**: Main hero section background (full-width at top of page)
- **Recommended size**: 1920x1080px or larger (landscape orientation)
- **Content**: Best photo of the resort showing mountains/views
- **Format**: JPG or PNG

### 2. `images/room-deluxe.jpg`
- **Purpose**: Deluxe Mountain View room card
- **Recommended size**: 800x600px (landscape)
- **Content**: Interior photo of the deluxe room
- **Format**: JPG or PNG

### 3. `images/room-executive.jpg`
- **Purpose**: Executive Suite room card
- **Recommended size**: 800x600px (landscape)
- **Content**: Interior photo of the executive suite
- **Format**: JPG or PNG

### 4. `images/room-family.jpg`
- **Purpose**: Family Room card
- **Recommended size**: 800x600px (landscape)
- **Content**: Interior photo of the family room
- **Format**: JPG or PNG

### 5. `images/location-map.jpg` *(Optional)*
- **Purpose**: Location section background
- **Recommended size**: 800x600px or larger
- **Content**: Map view or exterior photo showing location context
- **Format**: JPG or PNG

## Image Tips
- Use high-resolution images for best quality
- Compress images for faster loading (use tools like TinyPNG)
- Keep file sizes under 500KB each if possible
- Ensure good contrast for text readability
- Landscape orientation works best for web layouts

## After Uploading
Once you've uploaded the images, the website will automatically display them. If an image is missing, the site will fall back to a gradient background.
